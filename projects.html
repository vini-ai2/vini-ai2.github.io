Gridlock — AI-driven parking intelligence, Bengaluru

Hackathon submission · 2026

A full data pipeline for reading parking pressure across the city: DBSCAN clustering to surface informal parking clusters from raw location data, a custom PICRI (Parking Intelligence & Congestion Risk Index) score to rank risk per zone, and Random Forest feature importance to explain which variables were actually driving that score rather than just reporting it. Delivered as a full presentation deck built directly from the pipeline output.

ESP32 flight controller & stabilization

Group project · embedded systems · 2026

Built a custom drone around an ESP32, from motor mixing up. The stabilization loop initially fought itself — an inverted sign in the PID mixer logic meant correction torque was being applied backwards on more than one axis. Also corrected the ESC PWM protocol frequency, which had been running at 20 kHz against hardware expecting the standard 50 Hz, and calibrated an MPU-6050 complementary filter to get clean, drift-resistant attitude estimates. Separately debugged a PSRAM/DMA configuration issue on the ESP32-CAM module. Presented with slides, a spoken walkthrough, and the hardware live.

esp32c++pid controlmpu-6050esc / pwm

Real-time 3D face reconstruction (DECA)

Team project · computer vision · 2026

Took a research-grade 3D face reconstruction pipeline and made it run live off a webcam. Traced a bug where expression codes froze mid-session back to per-frame crop drift in the face detector, reconciled a coordinate space mismatch between two of DECA's output representations, fixed a crash inside extract_tex, and integrated a separately trained residual correction head into the runtime loop. Presented the internals — FAN landmark preprocessing, the coordinate pipeline, and weak perspective camera projection — to the team.

xv6-RISC-V — paging & swapping

Team project · operating systems · xv6-paging-and-swapping-v2

Extended the xv6-RISC-V teaching kernel with virtual memory paging and disk swapping. Owned the swap file interface (swapfile.c) and the page fault handler wired into usertrap(), then went past scope to reconstruct a teammate's Clock page replacement algorithm and help finish another teammate's PTE helper functions. Preparation meant going deep on PTE bit layout, frame table design, and FIFO / Clock / LRU replacement strategies.

Flux — real estate valuation environment

Meta PyTorch Hackathon

An OpenEnv-compatible reinforcement learning environment for real estate valuation, served through FastAPI with an LLM-driven inference agent making the valuation calls. Most of the work was in the unglamorous middle: fixing reward clamping that was silently distorting training signal, getting the environment subclass to actually conform to the OpenEnv interface, and untangling a dependency configuration that kept breaking the server.
